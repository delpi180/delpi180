## 🚀 Proyectos destacados

### [tesis-veterinaria](https://github.com/delpi180/tesis-veterinaria)
Sistema web de gestión clínica veterinaria con **asistente de IA**: transcribe la consulta por voz (Deepgram) y estructura automáticamente la historia clínica en formato SOAP (OpenAI). Incluye citas, inventario, ventas, dashboard de KPIs y roles de usuario.
`React 19` `Vite` `Tailwind` `FastAPI` `PostgreSQL` `Alembic` `JWT` `Pytest`

### [medasist](https://github.com/delpi180/medasist)
Demo de asistente de enfermería hospitalaria: panel de camas en tiempo real, doble barrera farmacológica ante alergias, registro por voz manos libres, calculadora de infusión y entrega de turno autogenerada.
`React 19` `TypeScript` `Tailwind` `Recharts` `Web Speech API`

### [cafeteria_zonatico](https://github.com/delpi180/cafeteria_zonatico)
Sistema para controlar ventas, inventario, gastos, cierre de caja y ganancias de una cafetería. Dinero manejado con `NUMERIC`/`Decimal`, migraciones con Alembic.
`FastAPI` `PostgreSQL` `React` `Tailwind` `Alembic`

### [EventProUni](https://github.com/delpi180/EventProUni)
App móvil Android para gestión de eventos con tres tipos de usuario.
`Kotlin`

> 🔒 También desarrollo sistemas para clientes: un CRM de e-commerce con bot de ventas por WhatsApp y landings de venta con checkout por WhatsApp. El código es privado, pero con gusto comento los detalles.
